# Utresebingo – Gran Canaria 2026

Mobilanpassad PWA för iPhone. Efter att GitHub Pages är aktiverat:
1. Öppna GitHub Pages-adressen i Safari.
2. Tryck Dela.
3. Välj Lägg till på hemskärmen.
4. Starta appen en gång med internet. Därefter fungerar den offline.

Filerna index.html, manifest.webmanifest, sw.js och ikonerna ska ligga i repositoryts rot.
